04. Featured Projects

Live Code

FitLog – AI Fitness Tracking Web App

  • Engineered a full-stack serverless fitness platform using Next.js 16 (App Router) with TypeScript, enabling calorie tracking, AI-powered meal logging, and workout analytics, deployed on Vercel with a Python service on Render.
  • Built a cascading LLM fallback pipeline (Gemini → Groq → OpenRouter) for natural language meal parsing; users type "2 rotis with dal" and the system identifies food items, maps them to a 150+ item nutritional database, and logs macros automatically with sub-3-second response time.
  • Designed a Repository Pattern (DAO) architecture separating API routes → Service layer → Prisma repositories → Supabase PostgreSQL, ensuring clean separation of concerns and type-safe data access across 10+ database models including meals, workout sessions, weight logs, and weekly insights.
  • Integrated Supabase Auth with Google OAuth and implemented Edge Middleware (Vercel Edge Runtime) for server-side session validation on every request; protected app routes redirect unauthenticated users in under 5ms without a cold start.
  • Applied Upstash Redis with sliding-window rate limiting on all AI endpoints and a TanStack Query cache layer with optimistic updates, so food logged via AI appears instantly in the UI with zero-latency feedback before server confirmation.
  • Built a Django 5.2 + DRF service on Render sharing the app's PostgreSQL, exposing share-link REST APIs (snapshot model, unguessable slugs, revoke/expiry → HTTP 410, per-user throttling) and a Django Admin for the food catalog; authenticated via a custom class verifying Supabase ES256 JWTs against cached JWKS, with pytest trust-boundary tests in CI.
  • Built a workout calorie burn estimator using MET (Metabolic Equivalent of Task) values and a compound/isolation exercise classification system to calculate burn ranges (e.g., "320–380 kcal") displayed as informational data, never double-counted against the daily budget.
